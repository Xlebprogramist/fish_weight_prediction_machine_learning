## Назначение

Оценка массы рыбы (г) по виду и трём измерениям тела для учебного прототипа
платформы FishGrow. Модель не предназначена для коммерческого взвешивания,
расчёта цены партии или решений, где ошибка в 8–10 % массы недопустима.

## Вход и выход

| Поле | Тип | Единицы | Используется |
|---|---|---|---|
| `Species` | строка | Bream, Parkki, Perch, Pike, Roach, Smelt, Whitefish | да (one-hot) |
| `Length3` | число > 0 | см | да |
| `Height` | число > 0 | см | да |
| `Width` | число > 0 | см | да |
| `Length1`, `Length2` | число > 0 | см | принимаются, но не используются (почти дублируют `Length3`) |

Выход — масса в граммах, всегда положительная (обратное преобразование `exp`).

## Устройство

```
Species             → SimpleImputer(most_frequent) → OneHotEncoder(handle_unknown="ignore")
Length3, Height, Width → SimpleImputer(median) → log(x)
регрессор: LinearRegression на log(Weight), прогноз = exp(ŷ)
обучение: 87 из 88 строк train (правило IQR по Weight убрало щуку 1550 г)
```

Модель в явном виде:

```
log(Weight) = −2.405 + 1.598·log(Length3) + 0.707·log(Height) + 0.697·log(Width) + сдвиг(вид)
```

Сумма показателей степени 1.598 + 0.707 + 0.697 = 3.00: масса растёт как куб
линейного размера, то есть пропорционально объёму. Модель физически
согласована с предметной областью.

## Как выбрана

По правилу, зафиксированному в `configs/base.yaml` до просмотра теста:
минимальная средняя MSE на CV (`RepeatedKFold` 5×3 внутри train), а среди
моделей в пределах одного std от лидера — самая простая. Лидер по CV —
`e2_ridge_loglog` (3270 ± 1358); `e1_esharma3` (3288) отстаёт на 0.6 %, это
меньше std, и это обычная МНК без подбора гиперпараметров.

## Качество

| Выборка | MSE, г² | MAE, г | R² |
|---|---|---|---|
| CV внутри train (среднее ± std, 15 разбиений) | 3288 ± 2058 | 32.3 ± 9.0 | 0.971 ± 0.013 |
| Тест (23 строки, один раз) | 1429 | 23.8 | 0.986 |
| Наивный прогноз среднего (E0), тест | 106 323 | 268.5 | −0.021 |

Относительная MAE стабильна по размерам — около 8 % (вне выборки: <100 г — 7.8 %,
≥700 г — 8.1 %). Отрицательных и бесконечных прогнозов нет ни на CV, ни на тесте.

95 %-доверительные интервалы (bootstrap, 10 000 повторных выборок): на тесте MSE
1429 [504; 2653], MAE 23.8 [12.7; 36.5] г, R² 0.986 [0.975; 0.992]; вне выборки на CV
MSE 2919 [1603; 4537], MAE 32.9 [24.5; 42.3] г. Модель значимо лучше линейных моделей
в граммах и ансамблей, но статистически неотличима от других лог-лог моделей.

## Интервал прогноза

Калиброван на остатках вне выборки (CV), проверен на тесте:

| Уровень | Интервал | Покрытие на тесте |
|---|---|---|
| 80 % | ŷ × [0.877; 1.124] | 91 % |
| 95 % | ŷ × [0.808; 1.208] | 100 % |

Интервал мультипликативный: его ширина пропорциональна прогнозу, нижняя граница
всегда положительна. Аддитивный интервал постоянной ширины (ŷ ± ~45 г на 80 %)
отвергнут: для рыб тяжелее 300 г его покрытие 44–62 % вместо 80 %
(`reports/lab02-report.md`, раздел 6а).
Тест лёгче CV: в нём нет рыб тяжелее 1250 г, поэтому основной оценкой качества
считать CV.

## Ограничения

- Обучена на 87 рыбах одного рынка; 4 вида из 7 представлены менее чем 15 экземплярами, Whitefish — тремя.
- Неизвестный вид не ломает модель, но получает нулевой сдвиг (усреднённый вид) — прогноз для него ненадёжен.
- Диапазон обучения: Length3 8.8–59.7 см, масса 5.9–1250 г. Для крупнее модель экстраполирует; щуку 1550 г она занижает на 13 %.
- Не учитывает упитанность, сезон, пол, наполненность желудка: два леща одной длины могут отличаться на 40 % (строки 4, 6, 68).
- Единицы измерения взяты из описания набора и проверены только косвенно.

## Признаки сдвига распределения после внедрения

- доля видов, отсутствующих в обучении, или резкое изменение долей видов;
- измерения вне диапазонов обучения, нарушение `Length1 ≤ Length2 ≤ Length3`;
- рост среднего остатка (систематическое занижение или завышение) на свежих взвешенных рыбах;
- изменение отношения `Weight / (Length3 · Height · Width)` по видам.
