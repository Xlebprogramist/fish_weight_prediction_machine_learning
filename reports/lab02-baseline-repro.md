```
Species → OneHotEncoder()
Length3, Height, Width → log(x)

```

## Найденные проблемы

1. **Оценка на обучающих данных.** Все 28 строк `fish_holdout_demo.csv` полностью
   содержатся в `fish_participant.csv` (проверка `merge` по всем 7 столбцам → 28 совпадений).
   `train.py` обучает модель на всём `fish_participant.csv`, значит MSE = 2330.62 из шага 3 —
   это ошибка на обучающей выборке, а не на отложенной. По разделу 7.1 общей инструкции
   это критическое нарушение, поэтому в ЛР2 тестовая выборка выделяется заново
   (см. `data/README.md`), а `fish_holdout_demo.csv` для оценки не используется.
2. **Выброс удаляется по жёсткому индексу** `df.drop([13])`. При другом порядке строк
   будет удалена другая рыба. В блокноте удаление сделано до разбиения на train/test.
   Сама строка 13 — щука 1550 г с правдоподобной геометрией (L3 = 64 см), это крупная
   особь, а не ошибка измерения.
3. **`OneHotEncoder()` без `handle_unknown="ignore"`** — пайплайн падает на виде, которого
   не было в обучении.
4. **Нет начального значения генератора** в `train.py`, нет контрольной суммы данных.
5. **Lasso в блокноте подбирается по MSE в лог-шкале** (`TransformedTargetRegressor`
   оборачивает `GridSearchCV`), а не по MSE в граммах; в сетке есть `alpha = 1e-15`.
6. **`log(x)` вместо `log(1 + x)`**: при нулевом значении признака или массы модель
   выдаёт `-inf`. Задание ЛР2 требует вариант `log(1 + y)`.
7. **`predict.py` требует столбец `Weight`** во входном CSV (через `prep_data`).
