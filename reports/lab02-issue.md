# Задача: ЛР2 — воспроизводимая регрессионная модель массы рыбы + MLflow

## Постановка

По измерениям рыбы (`Species`, `Length1`, `Length2`, `Length3`, `Height`, `Width`)
предсказать массу `Weight` в граммах. Исходный проект —
esharma3/fish_weight_prediction_machine_learning. Нужно собрать единую цепочку
предобработки и модели, честно сравнить наивное, линейное, регуляризованное и
нелинейное решения по MSE, MAE и R², зарегистрировать эксперименты в MLflow и
сформулировать ограничения прототипа.

## Критерии готовности

- [ ] исходный проект воспроизведён без изменений, результат записан;
- [ ] тестовая выборка заморожена до подбора признаков и гиперпараметров, индексы сохранены;
- [ ] модель выбирается по перекрёстной проверке внутри обучающей выборки;
- [ ] вся предобработка внутри одного `Pipeline` (`ColumnTransformer`);
- [ ] эксперименты E0–E4 выполнены на одном разбиении, метрики в одной таблице;
- [ ] каждый запуск записан в MLflow (параметры, метрики CV ± std, тест, прогнозы, графики, коммит, модель);
- [ ] анализ ошибок: остатки, топ-5 ошибок, MAE по видам и размеру, отрицательные прогнозы;
- [ ] не менее 5 быстрых тестов, `ruff` без ошибок;
- [ ] `src/train.py`, `src/evaluate.py`, конфиги, README, отчёт, паспорт модели;
- [ ] запрос на слияние с таблицей результатов и рецензированием, тег `v0.1` после приёмки.

## Риски

- выборка маленькая (111 строк), тест ~23 строки: разница моделей может быть в пределах шума → сообщать std по CV;
- редкий вид Whitefish (4 строки): метрики по нему неустойчивы;
- `fish_holdout_demo.csv` целиком входит в обучающий файл — нельзя использовать как тест;
- линейная модель в граммах может давать отрицательные прогнозы для мелких рыб;
- сильная мультиколлинеарность длин: коэффициенты линейной модели неустойчивы;
- исходный `reg.joblib` и `Pipfile` (Python 3.7) несовместимы с текущими библиотеками.
